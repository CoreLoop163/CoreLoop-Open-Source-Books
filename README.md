# 《前有数据结构》（若网页无法渲染，请下载pdf后观看）

《前有数据结构》中所有内容、插图、代码等均由CoreLoop本人一人精心打磨完成。

开源版pdf包含第五章《图》的全部内容、第四章《树与二叉树》的其中2节内容、第三章《栈和队列》的90%内容以及第二章、第一章和序章C和结构体、指针的部分内容。想开源的内容实在太多，但出于对自己的保护，虽然纠结了很多，
但精挑细选还是决定开源了很多。

本作品在组织编排上，传递知识的同时更加注重对读者严谨、细致、清晰的引导，来培养
读者的思维能力和创造力。相信大家在研读的过程中不只是能学到知识，更是能有“创
造”的快感，好像很多算法、理论都是自己创造出来的一样，这样，自然也会对它们记
忆深刻，历久弥新。

本作品涵盖了绝大多数理论与实际编程中最重要的内容，但我想它并不适合想要在短时间内准备笔试或机试的读者。

不过，对于想要踏下心来将内容真正搞透，或者为将来可能的算法竞赛/考研/机试等做准备的读者来说，我相信这部作品绝对不会是一部让大家觉得“浪费了时间”的作品，而是一部即使看了盗版也会想要“补票”的作品（就像我们玩游戏一样）。

当然，如果你们觉得本作品还不错，欢迎你们向同学、家人分享。同时，作品不好的地方更希望大家一定告诉我。一部作品的口碑从来不是靠说出来的，而是靠一个又一个读者真正体会出来的。
