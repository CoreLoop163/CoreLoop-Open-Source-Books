### 超越黑书！
​        **本作品涵盖了绝大多数理论与实际编程中最重要的内容，但这部作品不是为了应试而生，而是一部呕心沥血、精心打磨的，努力成为超越《算法导论》、《深入理解计算机系统》等“黑书”一样的传世经典。对于想要踏下心来将内容真正搞透，或者为将来可能的算法竞赛/考研/机试等做准备的读者来说，我相信这部作品绝对不会是一部让大家觉得“浪费了时间”的作品，而是一部即使看了盗版也会想要“补票”的作品。**

### 站在前人的肩膀上，走出自己的道路！
​        **本作品希望带给读者的，远不止知识本身。在笔者严谨细致、简单清晰的引导下你将一次又一次地体验那令人兴奋的瞬间：“原来如此”！ “原来这个数据结构是这样” ！“原来我也能创造出这个精妙的算法”！**
​        **当知识不再是需要反复背诵的结论，而是成为真正属于自己的东西，这样便自然会对它们记忆深刻，历久弥新，学习也会变成一件令人着迷的事情。** 
​        **我们希望，这本书不仅能让你掌握前人留下的智慧，更能让你拥有创造属于自己的智慧的能力。因为学习的终点，从来不只是理解世界，更是拥有用科技改变世界的能力。**

### 我们始终追求进步！
​        如果你们觉得本作品还不错，欢迎你们向同学、家人分享。同时，作品不好的地方更希望大家一定告诉我。一部作品的口碑从来不是靠说出来的，而是靠一个又一个读者真正体会出来的。**我们不会因为完成了创作就停止脚步，而会始终保持对进步的追求，认真倾听每一位读者的声音，不断修正、完善、打磨，让《前有数据结构》成为一部真正值得读者信赖与珍藏的传世佳作**！
